# Android 验收步骤

记录日期：2026-10-10。当前先使用 Expo Go 调试，不运行 EAS 云构建。真机检查项尚未执行，不能用单元测试或 Metro 打包替代。

## 连接手机

1. Android 手机安装 [SDK 54 对应的 Expo Go](https://expo.dev/go?sdkVersion=54&platform=android&device=true)。它是调试客户端，不是 CardBox 的最终 APK。
2. 手机和电脑连接同一局域网。电脑有多张网卡时，使用手机所在网络对应的 IPv4 地址。
3. 在项目根目录运行 `pnpm dev:mobile`，保持终端运行。
4. 在 Expo Go 扫描终端中的二维码，或手动输入 `exp://电脑IPv4地址:8081`。启动后代码修改可通过 Fast Refresh 更新，无需重复编译 APK。
5. 如果连接失败，先用手机浏览器访问 `http://电脑IPv4地址:8081/status`，正常应显示 `packager-status:running`。检查网络隔离、VPN 路由与防火墙，不要直接转向云构建。

Expo Go 数据属于该调试客户端。正式 CardBox APK 的应用目录和设备密钥不同，迁移时使用加密 `.cardbox` 备份。

## 当前边界

- Web 仅用于布局与普通交互预览，不执行原生身份验证或后台锁定。浏览器密钥与数据位于同一浏览器存储，不能代表移动端保护能力。
- Android 卡片字段加密保存，设备密钥使用 SecureStore；卡面文件保存在应用私有目录，没有单独加密。备份会一起加密卡片字段和图片内容。
- 本地数据采用带完整性校验的新格式；正常修改时重新加密。旧版合法明文或旧加密数据可以读取，不在初始化时自动改写。
- v3 备份具有完整性校验；v2 备份仅为兼容读取，旧格式本身没有完整性标签。
- 卡面按固定银行卡比例居中裁剪；到期时间使用 MM/YY 输入；交互裁剪与月份选择器尚未增加。
- 备份密码派生使用 JavaScript PBKDF2，较慢手机上的处理时长需要验收。界面显示处理中；超过 50 MB 的备份拒绝处理。
- iOS Face ID 在 Expo Go 中不可验收；本阶段优先 Android。

只有真机验收通过并确认需要安装包后，再选择本机 Android 编译或 EAS preview 构建。任何 EAS 云构建都需用户明确确认，以保护免费额度。
