## 当前边界

- Web 仅用于布局与普通交互预览，不执行原生身份验证或后台锁定。浏览器密钥与数据位于同一浏览器存储，不能代表移动端保护能力。
- Android 卡片字段加密保存，设备密钥使用 SecureStore；卡面文件保存在应用私有目录，没有单独加密。备份会一起加密卡片字段和图片内容。
- 本地数据采用带完整性校验的新格式；正常修改时重新加密。旧版合法明文或旧加密数据可以读取，不在初始化时自动改写。
- v4 备份具有提前密码检查与完整性校验，仍需完成 120,000 轮派生；旧 v3 有完整性校验并继续读取，v2 仅为兼容读取，旧格式本身没有完整性标签。
- 卡面按固定银行卡比例居中裁剪；到期时间使用 MM/YY 输入；交互裁剪与月份选择器尚未增加。
- 3.0.1 移动端密码派生通过离线系统 WebView 的本机 WebCrypto 处理；保持完整参数，服务错误 / 超时明确失败，不回退到慢路径。界面显示读文件、验证密码、恢复图片等阶段；超过 50 MB 的备份拒绝处理。真机密码 / 加解密合成耗时已测，文件提供器耗时待用户操作复测。
- 2.0.0 保持原有密码派生参数，改用较轻量的 HMAC-SHA256 实现并定时让出界面线程；显示读取、加密、选择目录及写入校验进度。Android 导出回读校验所选目录中的文件，成功提示包含文件名。
- iOS Face ID 在 Expo Go 中不可验收；本阶段优先 Android。

只有真机验收通过并确认需要安装包后，再选择本机 Android 编译或 EAS preview 构建。任何 EAS 云构建都需用户明确确认，以保护免费额度。
