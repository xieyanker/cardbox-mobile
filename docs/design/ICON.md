更新日期：2026-10-13。当前版本 4.0.0 使用用户确认的三卡叠放图标。

## 当前设计

![CardBox 三卡叠放应用图标](../../assets/images/icon.png)

三张卡片从后到前为深蓝、青绿和米白，按相同角度向右上倾斜，两侧竖直，向右下错位叠放。保留卡面左上角的小标记与柔和质感，去掉原图的卡夹、CardBox 文字和斜向反光分界。颜色、圆角、间距与边缘处理统一，便于在小尺寸下辨认。

用户在本轮逐步确认造型、配色和细节，最终授权接入应用。设计使用内置 imagegen 生成和调整；已确认的原始图保存在 `assets/branding/cardbox-approved-artwork.png`，平台资源由同一图稿导出，不再分别重绘。

## 重新生成

安装项目依赖，并确保本机可使用 Google Chrome 后执行：

```powershell
node scripts/generate-brand-assets.cjs
```

脚本使用 Playwright Canvas 将已确认图稿与固定轮廓蒙版合成，规范透明边缘、方形画布和平台尺寸；单色图使用同一轮廓并镂空小标记。生成后检查不透明资源的 alpha、有效像素及 Android 安全圆。手工修改确认原稿的比例或布局时，须同步检查脚本中的轮廓坐标，不应直接用新图覆盖而跳过视觉检查。

视觉检查包括浅色 / 深色衬底、圆形 / 圆角方形裁切及小尺寸效果。Web 关于页和文档演示图可验证引用，但安装图标、系统主题图标与原生启动画面仍需新 APK 真机验收。

## 设计提示词与加工

最终设计要求：保留三张卡片的大小、角度、位置和叠放布局；从后到前为深蓝、青绿与米白；去除全部斜向反光分界，卡面仅保留连续柔和色调；减弱荧光高光和厚重边缘；统一圆角、小标记和间距；无卡夹、无文字、无额外装饰。

使用内置 imagegen 编辑已确认图稿。平台导出采用原稿的固定轮廓蒙版，避免透明背景提取改变米白卡片或留下杂色边缘；导出过程不会改变卡包、加密数据或备份。
