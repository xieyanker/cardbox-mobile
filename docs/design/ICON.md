# CardBox 3.0 图标

2026-10-11 使用内置 imagegen 生成原创图标。设计为三张深蓝、青绿与米白卡片收纳在卡包中，下方包含完整的 **CardBox** 字样。应用图标使用浅色背景；Android 自适应前景和启动标志保留透明背景；主题图标使用单色前景。

生成原图保存在 `assets/branding/`，实际应用资源保存在 `assets/images/`。使用项目已有的 Expo 图像工具导出平台尺寸：

```powershell
node scripts/generate-brand-assets.cjs
```

Android 自适应与单色前景增加透明留白，使图形和文字位于 66% 直径安全圆内；应用图标是 1024 × 1024 不透明 PNG，Web 图标为 256 × 256。配置在 `app.config.ts`，启动画面背景与图标统一为 `#F2F6F5`。

## 生成提示词

主标志：制作 CardBox 本地银行卡管理应用的简洁、精致标志。三张圆角卡片叠放在卡包中，以深蓝 `#142B45`、青绿 `#35C9B6` 和米白为主色，采用干净几何形状与轻微立体渐变。下方使用粗体几何无衬线完整写出 “CardBox”，C、B 大写。正方形透明画布，居中，保留充足安全留白；无其他文字、卡号、银行品牌、水印或设备模型。

应用图标变体：仅将主标志透明背景替换为浅色 `#F2F6F5`，保留图形、文字、构图和留白，输出无外部圆角的完整正方形。

主题图标变体：将主标志转为透明背景上的黑色单色轮廓，保留卡片、卡包和 “CardBox” 字样，以透明负形分隔卡片；无彩色、灰色渐变或白底矩形。

图标、启动画面等原生安装资源在新安装包中生效；Expo Go 的桌面图标由 Expo Go 自身控制。
