## 文档维护约定

首页保留产品介绍、版本状态和入口；操作与截图集中在功能说明，调试和待验收步骤集中在验收文档，技术细节放在开发指南，阶段证据写入对应版本记录。历史资料保留原版本语境。

开始新版本时同步应用版本、Android 构建编号和当前文档状态；用户亲自验收并明确授权后才封板。演示图更新保留用户真机照片、原始原型与历史设计图片。完整开发约束见 [AGENTS.md](../AGENTS.md)。
