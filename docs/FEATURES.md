# CardBox 功能与使用说明

适用版本：**4.0.0**（Android 构建编号 8），用户已确认验收并授权源码封板，APK 已在 GitHub Releases 发布。更新日期：2026-10-21。

[返回项目首页](../README.md) · [文档目录](README.md) · [下载 4.0.0 Android APK](https://github.com/xieyanker/cardbox-mobile/releases/download/4.0.0/CardBox-4.0.0-android.apk)

CardBox 是一个资料保存在本机的数字卡包。无需创建账号，可以管理借记卡、信用卡和虚拟卡，选择不同的浏览方式，并通过密码备份迁移或恢复卡包。

本页功能与截图对应 4.0.0，已发布的 3.0.2 不包含全部新功能。现有演示图采集于 2026-10-14，10 月 21 日的编辑与拖动修复以文字说明为准。演示图使用虚构卡片，来自 Web 移动视口；来源与真机验收边界见[截图与版本记录](#截图与版本记录)。

## 首页与四种浏览模式

| 模式 | 怎么浏览                                                     | 适合的体验                                 |
| ---- | ------------------------------------------------------------ | ------------------------------------------ |
| 经典 | 左右滑动或点击左右箭头；卡面下方直接显示卡片资料。           | 一张一张查看，并快速查看资料、修改或删除。 |
| 钱包 | 上下滑动，卡片呈卡槽分层效果；点击卡片或“查看详情”打开资料。 | 像翻看实体钱包一样选择卡片。               |
| 堆叠 | 上下滑动，多张卡片叠放；点击卡片查看详情。                   | 通过卡片层次感浏览卡包。                   |
| 聚焦 | 上下滑动，突出当前卡片，前后卡片作为浏览参照。               | 把注意力集中在当前选择的卡片。             |

默认顺序是 **经典 → 钱包 → 堆叠 → 聚焦**。切换模式后自动保存，下次打开沿用上次选择。新模式滑到第一张或最后一张时保留边界，经典模式支持循环切换。

从右上角菜单进入 **浏览模式**，长按模式或左侧把手拖动，松手后自动保存首页选项顺序；也可使用上下箭头。“恢复默认顺序”还原默认排列。卡片本身的顺序在“卡片排序”中单独调整。Web 触屏拖动使用把手，行内其他区域保留普通滑动。

## 添加、修改与卡面

首页右上角菜单第一项为 **添加卡片**；“全部卡片”页面也保留右下角添加按钮。可以填写名称、类型、卡号、CVV、到期时间和备注，或选择本机图片作为卡面。4.0 支持拖动裁剪、缩放、旋转、照片遮挡和移除图片；遮挡会写入新卡面的像素，原相册照片保持原样。

名称和卡号需要填写；CVV、到期时间和备注可以留空。4.0.0 的到期时间使用单个 `__/__` 掩码输入框，连续输入 `0726` 自动显示为 `07/26`，无需手动输入斜杠；支持退格、粘贴与选中替换。保存格式仍为 `MM/YY`，兼容已有卡片与备份；保存时检查月份和完整格式。保存后自动选中新卡片。已有卡片可以从详情区点击“修改”，或点击“删除”并确认。

新建和编辑页的 CVV 直接显示，方便核对；首页与详情仍按原有规则隐藏敏感信息。裁剪图片和移动遮挡条时，弹层不会跟着滚动；图片只能在保证卡面填满的范围内移动，放大后可获得更大的调整空间。

粘贴 `07/2026` 也会正确转换为 `07/26`，无效长输入会提示。卡号按四位分组显示，保存与复制使用纯数字；遇到重复卡号可以取消或确认保存。离开已修改的编辑页先询问保存 / 放弃 / 继续；自动锁定后验证身份可恢复本次会话草稿。到期月份最后一天之后标为“已到期”，90 天内到期标为“即将到期”，过期卡仍可保留。

### 信用卡账单日与还款日

选择“信用卡”后，可分别填写账单日和还款日，范围为每月 1—31 日，两项均可留空。详情页显示“每月 X 日”；仅记录，不发送通知、不推算账期或还款金额。修改类型时保留已填日期，切回信用卡后可继续编辑；实际日期以银行账单为准。

日期随卡片加密保存、导出、导入和恢复。旧卡片没有这两项时显示未填写；本版可以读取旧卡包和备份。旧版本可能忽略新增字段，降级后再次保存或导出可能丢失日期记录。

## 全部卡片与卡片排序

点击首页右上角的网格按钮进入 **全部卡片**，通过双列卡面快速找到目标卡片；点击卡片返回首页并选中它。

4.0 支持名称或卡号后四位搜索、类型筛选和仅看常用卡；详情可设为常用，常用卡在全部卡片中置顶。重新打开应用记住上次选中的卡片。列表和排序按需渲染，适用于较多卡片。

菜单的 **卡片排序** 或全部卡片页面的排序入口，可打开排序列表。长按卡片或左侧把手拖动到列表上边缘或下边缘，保持按住即可自动滚动到其他卡片；移回中间停止，松手后保存顺序。Web 触屏拖动使用把手，行内其他区域保留普通滑动。拖动预览显示目标位置，跨屏时持续跟随；取消或离开页面不会保存本次拖动。也可点击上下箭头移动。保存后的顺序用于首页全局浏览，失败时保留原顺序并提示。

## 密码加密备份

### 导出

进入 **备份管理 → 导出备份**，设置至少 8 位的密码并再次确认，生成 `.cardbox` 文件。默认一起加密卡片和图片；也可明确选择仅备份资料。页面显示最近成功导出时间和此后卡片变更数量。Android 生成后选择文件夹并回读校验，iOS 分享结束后确认已保存才更新记录。请妥善保存文件与密码，密码丢失后无法恢复。

### 导入

进入 **备份管理 → 导入备份**，选择文件、输入原密码（兼容旧短密码）。替换模式预览数量和名称后确认；合并模式遇到重复卡号先进入“导入冲突比较”，显示名称、类型、到期、账单日、还款日、备注及卡面来源等差异，CVV 仅提示是否不同，不直接展示安全码。

每项默认“保留本机”（备份内部重复为“保留前项”），即跳过该备份条目；选择“采用备份”会替换整张卡片资料和图片，包括备份里的空字段。本机卡片 ID、位置和常用状态保留。同卡号存在多张本机卡时比较第一张，其余保留；备份内部重复按文件顺序处理，后项会与前项选择结果比较。确认前显示新增、更新和跳过数量。取消、离开页面或锁定会丢弃待导入内容，不写入卡包。

操作前保存本机加密恢复点，保存失败就中止；可以使用“恢复上次导入前卡包”恢复最近一次快照。恢复点保留其图片，恢复不会关闭已开启的照片隐私设置。只恢复最终选中条目的图片，写入失败清理本次新图片并保留原卡包。

## 敏感信息与自动锁定

卡号和 CVV 默认隐藏。移动端显示敏感信息、修改、删除、导入、导出和调整自动锁定设置时，使用系统身份验证，支持设备可用的生物识别或锁屏密码。切换卡片、切换模式或进入后台时重新隐藏敏感信息。

4.0 提供独立验证后复制卡号 / CVV，显示的敏感信息 30 秒后自动隐藏。自动锁定页面可开启“照片隐私模式”，开启后卡面照片只在验证显示敏感信息时短暂显示；设置未读取成功时先隐藏照片。原生接入截图 / 录屏保护，Android 最近任务预览使用系统保护；Web 预览不具备这些系统保护。

应用切到后台后遮挡内容，返回时按设置决定是否重新验证。可选择 **立即锁定、1 分钟后锁定、5 分钟后锁定、不自动锁定**；冷启动始终需要验证身份。

<img src="images/lock-settings.png" width="280" alt="后台锁定时限、照片隐私模式开关和立即锁定按钮" />

卡片字段在本机加密保存，移动端设备密钥使用系统安全存储。卡面图片保存在应用私有目录，未单独加密；照片本身含有卡号时，需自行遮挡图片中的号码。Web 预览用于界面展示，不替代移动端身份验证与存储安全验收。
