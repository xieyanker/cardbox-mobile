## 查找、录入与浏览

- “全部卡片”支持名称 / 卡号后四位搜索，类型筛选、仅看常用；常用卡在此页面置顶，不重写用户保存的全局顺序。
- 详情可设为 / 取消常用；卡号按四位分组显示，复制时输出纯数字。卡号与 CVV 复制独立验证身份，不自动显示其他敏感字段。
- 新增或修改遇到重复卡号时确认，可取消，也允许用户继续保存；到期状态按月份最后一天判断，未来 90 天内显示“即将到期”，过期显示“已到期”，均允许保存。
- 重新打开记住上次选中的卡片；目标已删除时回到现有第一张。列表与排序使用 FlatList 按需渲染；排序支持长按把手拖动和箭头，松手后统一提交一次顺序。
- 浏览模式与常用设置写入失败不显示虚假成功；原数据保留，提示重试。

## 备份与恢复保护

- 导出显示上次成功导出时间、是否包含图片，以及相对该份快照新增 / 修改 / 删除的卡片数量；记录以本机密钥加密保存。导出密码至少 8 位，并需要再次确认；旧备份导入仍接受原有短密码。
- 默认包含图片；可明确选择“仅备份卡片资料”，缺失图片不会阻止此选项，原卡片的图片字段不被修改。
- 导入在解密后预览卡片数量、图片数量和前五张名称，再确认“替换卡包”或“合并导入”。合并保留现有卡片，重复卡号（含备份内重复）跳过，冲突 ID 重新生成；合并不能超过原有 1000 张限制。
- 替换或合并前保存一份本机加密恢复点，含卡片与常用设置。恢复点保存失败立即中止导入；卡片写入失败丢弃本次新建的图片。恢复点保留其原图片引用，清理不会删除这些图片。
- “恢复上次导入前卡包”再次验证和确认后恢复此快照；当前原始数据无法读取时继续走原有保留原数据的恢复流程。恢复点仅保留最近一次，不替代外部加密备份。
- Android 文件写入后继续回读校验；iOS 分享结束后确认已保存，才更新成功导出记录。换机 / 卸载前提示导出 .cardbox，系统迁移不作为可恢复性保证。

## 卡面、存储与隐私

- 新卡面支持拖动调整裁剪位置、1–4 倍缩放、90 度旋转、可移动及调节厚度的遮挡条。遮挡条写入新生成图片的像素；不修改原相册图片。保存前可取消或重新选择。
- 编辑页可移除图片恢复默认卡面。图片读取失败回退到默认卡面；旧应用容器根路径变化时，对应用自有 cardbox-images 文件名解析到当前目录，读取不改写原数据。
- “照片隐私模式”默认保留旧用户照片展示体验；开启后首页、卡片列表、排序和动画卡面隐藏照片，验证显示敏感信息后在详情短暂展示。设置未读取或损坏时优先隐藏照片。
- 敏感信息 30 秒后自动隐藏；首页菜单和自动锁定页面增加“立即锁定”。原生接入截图 / 录屏保护，Android 最近任务预览使用系统保护；Web 预览不提供系统保护。
- “存储管理”查看应用自有卡面数量、占用和无引用文件；确认后只清理当前卡包、恢复点以及草稿都没有引用的应用图片。Web 图片随加密卡包保存，没有原生图片目录清理。

## 旧数据兼容与实现边界

- 应用包名保持 com.app.cardboxmobile，版本 4.0.0 / 构建编号 8；原有 cardbox.cards.v1、卡片字段、cardbox-local-v2、本机密钥以及密码派生参数保持兼容。
- 新设置使用独立 cardbox.preferences.v1，只有卡片 ID 和照片显示开关；成功导出记录与恢复点分别使用 cardbox.backup-record.v1、cardbox.restore-point.v1，并加密保存。不会把草稿、卡号或 CVV 写入明文设置。
- 新导出仍为 cardbox-secure-v4，内部卡片载荷仍为 version: 3；额外可选 preferences 保存常用卡 / 选卡位置 / 照片隐私开关，旧读取器可忽略该字段。继续读取 v2 / v3 / v4。2.0.0 不能读取 v4 是既有边界，本轮没有新增此限制。
- 旧文件没有 preferences 时按既有字段恢复；合并保留当前设置，替换也不会通过导入关闭已经开启的照片隐私。自动锁定和浏览模式顺序继续是本机设置。
- 首次读取旧卡包不迁移、不改写。草稿只保留本次运行会话，进程被系统结束后不保证恢复；锁定时全部业务内容位于门禁之后，解锁后恢复编辑。
- 新增 SDK 54 配套 expo-clipboard、expo-screen-capture、react-native-view-shot；正式原生能力需匹配模块的 Expo Go 或重新构建的安装包。只生成 Android 代码包，不消耗 EAS 构建额度，不创建发布 tag。

## 到期时间输入

单个输入框始终显示 `__/__` 掩码。连续输入 `0726` 后显示 `07/26`，自动跳过固定斜杠，使用数字键盘。支持退格到空、选择月份或年份替换、清空，以及粘贴 `0726` 或已有 `07/26` 格式。仍允许留空；月份范围及完整格式在保存时校验。

掩码只用于编辑显示，保存格式仍是原有空字符串或 `MM/YY` 字符串；不保存下划线。卡片字段结构、存储键、本地加密格式、备份格式和密码派生参数保持原样。读取旧数据不触发写入或迁移。

真机验收待用户执行：

1. 新建卡片，连续输入 `0726`，确认显示 `07/26`，保存后再次打开确认值正确。
2. 从末尾连续退格，确认可删到空，斜杠仍显示；空到期时间可保存。
3. 编辑已存在卡片，选择月份或年份替换，修改其他字段后确认原到期时间仍保留。
4. 升级前后确认已有卡片、图片、排序及设置正常；使用手头旧备份检查导入、编辑与再次导出。
5. 未保存返回分别测试保存、继续、放弃；编辑中进入后台超过锁定时限，解锁后内容仍在。系统结束进程后草稿恢复不属于当前会话保证。
6. 搜索 / 类型筛选 / 常用卡 / 重启选卡；验证后复制卡号和 CVV；长按把手排序及大字体、小屏操作。
7. 照片裁剪拖动、旋转、缩放、遮挡及取消；保存后的遮挡真实存在；照片隐私开关、30 秒隐藏、截图 / 录屏与最近任务预览保护。
8. 替换 / 合并 / 导入前恢复点、短密码旧备份、缺失图片时仅导出资料；确认原卡面和恢复点图片不被清理。测试磁盘不足时原卡包仍在。
9. 用真实 Android 旧 APK 覆盖升级，核对包名 / 签名 / 卡片 / 图片 / 设置；另在测试设备上验收换机、系统恢复与独立 .cardbox 恢复，不以 Web 结果代替。

本轮不创建 tag，不生成或发布 APK；Android 键盘与光标行为以用户真机验收为准。
